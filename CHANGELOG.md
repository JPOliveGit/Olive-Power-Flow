# Changelog

## 0.1.1

- Default to the entire section width instead of a fixed 12-cell span.
- Include full-width layout when creating cards from the picker.
- Add a visual editor width toggle to migrate existing cards with saved numeric widths.
- Test a 36-column section and parent resizing while keeping circles at 96 px.

## 0.1.0

- Visual sensor configuration with production and consumption counts.
- Optional battery, signed power flows and configurable signal inversion.
- Computed house power: production + grid + battery.
- Fixed-size circles, responsive rows and native HTML icon placement.
- W/kW input support, W display, unavailable-state handling.
- HACS repository metadata, validation and release workflows.
